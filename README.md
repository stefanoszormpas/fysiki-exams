# fysiki-exams
GRE-style εξετάσεις φυσικής ανά κεφάλαιο (Français / Ελληνικά).

- `index.html` — η εφαρμογή (ενότητες με χρονόμετρο, επισκόπηση, σήμανση, κομπιουτεράκι, τύποι, αποτελέσματα 0–100)
- `exams/kef1.js` — εξέταση Κεφαλαίου 1 (Κινηματική στο επίπεδο)
- `exams/kef2.js
  exams/gr-b1.js   (Β΄ Λυκείου — Οριζόντια βολή & ΟΚΚ, μόνο ελληνικά)` — εξέταση Κεφαλαίου 2 (Δυναμική)
- `exams/figs.js` — βοηθοί για σχήματα SVG (γραφήματα, κεκλιμένο επίπεδο, κρούσεις)

Νέο κεφάλαιο: αντιγράφεις το `exams/kef2.js` ως `exams/kefN.js`, αλλάζεις το περιεχόμενο και προσθέτεις μια γραμμή
`<script src="exams/kefN.js"></script>` στο `index.html`. Δουλεύει και ανοίγοντας το `index.html` τοπικά.

Τύποι ερωτήσεων: `single`, `multi`, `numeric`, `compare`. Σε όλους τους υπολογισμούς g = 10 m/s².


## Ελληνικά τεστ (φροντιστήριο)
Στο αντικείμενο της εξέτασης βάζεις `lang: "el"` και `group: "Β΄ Λυκείου — Φυσική"`. Τα κείμενα γράφονται ως απλά strings (όχι `{fr, el}`), και το app κλειδώνει στα ελληνικά.
